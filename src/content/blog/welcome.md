## 技术栈

这个站点采用了 2026 年的前沿组合：

- **Astro 7** — 内置 Rust 编译器，构建速度相比 v6 提升 61%
- **Tailwind CSS 4** — CSS-first 配置，无 config 文件
- **Content Layer API** — 内容与渲染分离，Zod schema 校验
- **GitHub Actions** — 工作流模式部署，告别 gh-pages 分支
- **GitHub Pages** — 免费静态托管，全球 CDN
